# seangartland.com

Personal portfolio and resume site for Sean Gartland — data analytics leader specializing in AI-powered insights, automation, and self-service analytics.

**Live:** [seangartland.com](https://seangartland.com)

## Tech Stack

- **HTML / CSS / JavaScript** — vanilla, no build step
- **Google Fonts** — Roboto Serif
- **Vercel** — deployment and hosting

## Structure

```
index.html          # Main portfolio (hero, about, experience, projects, skills)
resume.html         # Printable resume with dark mode toggle
style.css           # Global styles
script.js           # Mobile menu, scroll effects, typing animation
favicon.svg         # Site icon
assets/
  headshot/         # Profile photo
  projects/         # Project preview images
```

## Local Development

No build tools required — just open `index.html` in a browser, or use a local server:

```bash
npx serve .
```

## Deployment

Push to `main` — Vercel auto-deploys from the GitHub integration.
